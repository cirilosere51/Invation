# Gembert Walog & Princess Torreon Wedding Invitation

A romantic animated wedding invitation built with HTML, CSS, JavaScript, and TypeScript using Vite.

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Open the local URL shown in the terminal.

## Deploy to GitHub

```bash
git init
git add .
git commit -m "Initial wedding invitation"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repository>.git
git push -u origin main
```

## Deploy to Vercel

```bash
npx vercel
```

Then follow the prompts in the Vercel CLI to link the project to your Vercel account and deploy it.
